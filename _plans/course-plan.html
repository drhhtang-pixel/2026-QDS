現況與主要問題

面向現況問題
風格每份講義各自用 Tailwind CDN 寫，大多來自 claude.ai artifact沒有共用範本，每份重新設計，容易慢慢走樣
效率新增一堂要改 build.py、手動 build、提交 2.4 MB 建置產物改一個字，repo 就多存一份 2.4 MB
Agent都在同一個對話裡依序做沒有可重複使用的 SOP、分工角色或自動檢查
中國學生GitHub Pages、Google Fonts、cdn.tailwindcss.com在中國大陸大多被擋或極不穩定
中國大陸的問題比表面嚴重：
  • fonts.googleapis.com 被封鎖，而且它是會擋住畫面的樣式表，瀏覽器要等到逾時，畫面先空白很久。
  • cdn.tailwindcss.com 很不穩定，載入失敗時整份講義完全沒有版型。
  • github.io 時通時斷，而且很慢；第三堂一頁就 2.4 MB。

9/30–10/6A. 讓中國學生看得到

第一層：網頁「零外部請求」（台灣學生也會變快）

  • Tailwind 建置時編譯：用官方單一執行檔（不需 Node），只留實際用到的 CSS（約 10–20 KB）內嵌，拿掉 CDN 腳本
  • 拿掉 Google Fonts：改用系統字型 "PingFang TC","Noto Sans TC","Microsoft JhengHei",sans-serif
  • Font Awesome 已內嵌，維持不變
  • 圖片轉 WebP 並壓縮（第 1、6 份講義各約 1 MB，主要是圖片）
  • 自動檢查：build.py 發現任何外部網址就中止建置

第二層：中國連得到的鏡像站

選項大陸速度成本／門檻建議
台科大學校網頁空間（電算中心）通常可連免費，要向學校申請首選
阿里雲 OSS／騰訊雲 COS 香港區靜態網站快每月幾十台幣，香港區不需 ICP 備案替代方案
Cloudflare Pages / Vercel / Netlify常被限速或封鎖免費不建議
Gitee Pages已停止服務—不可用
大陸境內主機最快需 ICP 備案，台灣個人實務上很難不建議
  • 老師選定鏡像站並取得帳號
  • GitHub Actions 部署時同步上傳到鏡像站
  • 第三層離線備援：每堂加「下載本堂講義」按鈕（單一 HTML 檔，可用微信或 email 傳遞）
  • 驗證：用 17ce／boce 等中國測速服務測鏡像站，並請一位在中國的學生實測（不可省略，Claude 無法模擬大陸網路）

B. 風格一致：建立設計系統

  • design/tokens.css：色系（slate/indigo、4 個單元色標）、字型、圓角、間距
  • design/components.html：深色漸層頁首、白底卡片、比較表、提示框、APA 參考文獻列表、跳分頁連結、小測驗面板
  • sources/_template/lecture.html：新講義的起始範本
  • 風格指南頁發布在 /2026-QDS/style/，老師能直接看到每個元件的樣子
  • 小測驗通用化：把 apa_quiz.html 的測驗引擎抽出來，之後每堂的課後小測驗只要寫題目 JSON
  • 舊講義（第三堂第 1～6 份）維持補丁方式；新講義一律從範本開始

C. 效率：新增一堂只需「放檔案＋填設定」

  • 每堂設定移到 sources/weekNN/week.json（分頁名稱、順序、來源檔、更新紀錄），新增一堂不用改 build.py
  • GitHub Actions：推送後自動 build、檢查、部署 Pages 與鏡像站；建置產物不再提交進 repo（Pages 來源改為 GitHub Actions）
  • 每堂一個分支＋PR 預覽：Claude 在分支上做，老師看預覽，確認後合併才上線
  • Notion：先試用 Notion 連接器讀「2026 Course Schedule Master」；讀得到就自動同步 SCHEDULE 與搬課堂筆記，讀不到就照原計畫用 zip 匯出
  • 建立 inbox/weekNN/ 收件夾慣例，附 00-說明.md（分頁名稱、順序、重點）

D. 善用 Agent：建立分工角色（放在 .claude/）

角色工作
Skill new-week新增一堂的標準流程（SOP），把 CLAUDE.md「新增一堂課」寫成可執行步驟
handout-builder把一份原始資料（PPT／PDF／.md／Notion 頁）依範本轉成講義；每份講義一個 agent，平行處理
style-reviewer對照設計系統，列出不一致之處
apa-checker檢查書目是否符合 APA 7（期刊名與卷號斜體、en dash），並上網核對 DOI
zh-tw-proofreader正體字、台灣用語（視頻→影片、質量→品質），確認「老師」稱謂
qa-tester用 Playwright 點過每個分頁，抓 JS 錯誤、截手機版畫面，並封鎖所有外部網域模擬中國網路
quiz-maker依講義草擬課後小測驗，交給老師審核
  • 建立上表的 skill 與 agent 定義檔
  • Routine（排程）：每週一早上比對 Notion 進度表與 SCHEDULE、測試鏡像站是否可連、提醒下週三那堂還缺哪些講義
